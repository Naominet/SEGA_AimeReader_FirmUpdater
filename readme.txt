同梱ファームについて

第一世代リーダー　HEXデータについて		
 R/W
【TN32MSEC003S_V12.hex】

  F/Wバージョンが" TN32MSEC003S F/W Ver1.2 "
　このバージョンからNFCThrough,Pushコマンドが使用可能です。（FeliCa内部
　データを読む際に使用します。）  

 LED
【837_15084_1_01.hex】

　F/Wバージョンは" 1.01 -> 0x11 "
